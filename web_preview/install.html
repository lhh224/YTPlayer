iOS Configuration Profile • v1.0
📲 Cài đặt Hồ sơ App (iPhone) Dự phòng: Tải trực tiếp Profile (nếu dùng trình duyệt khác)
Hướng dẫn kích hoạt trong 15 giây (Mở bằng Safari)
1. Bấm nút đỏ Cài đặt Hồ sơ App ở trên → chọn Cho phép (Allow).
2. Mở ứng dụng Cài đặt (Settings) trên iPhone → nhấn vào mục Đã tải về hồ sơ (Profile Downloaded) ngay đầu trang.
3. Bấm Cài đặt (Install) ở góc trên phải → nhập mật mã mở khóa iPhone → bấm Cài đặt → Xong.

Lưu ý: Hãy mở trang này bằng Safari trên iPhone để iOS tự nhận diện hồ sơ cấu hình.
